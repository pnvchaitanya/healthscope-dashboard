## Overview
A Power BI dashboard analyzing 50K+ global health records across 150 countries,
covering healthcare access, facility density, and treatment costs.

## Key Features
- Recovery, prevalence, and mortality trend analysis (2000–2024)
- Healthcare resource vs. mortality scatter plot by country
- Country and year slicers for interactive filtering
- Star schema data model with automated ETL refresh

## Tech Stack
- **Visualization**: Power BI Desktop
- **Data preprocessing**: Python (Pandas)
- **Metrics**: DAX measures
- **Dataset**: [Global Health Statistics – Kaggle](https://www.kaggle.com/datasets/malaiarasugraj/global-health-statistics)

## Key Insights
- Mortality rate has slightly decreased in the last 5 years
- Countries with higher doctor density show lower mortality rates
- Treatment cost variance is 3× across demographic groups

## How to Run
1. Download `HealthScope.pbix`
2. Open in Power BI Desktop (free)
3. Reconnect the data source to your local CSV from Kaggle
